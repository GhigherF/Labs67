# КИС — лабораторная работа № 3, вариант 2

Все диаграммы и шаблоны находятся в формате draw.io и редактируются в diagrams.net.

## Готовые схемы

1. `01_IDEF0_A-0_Context.drawio` — контекстная диаграмма приёма и регистрации пациента.
2. `02_IDEF0_A0_Decomposition.drawio` — декомпозиция A-0 на четыре функциональных блока. Подписаны граничные и внутренние стрелки ICOM: входы слева, управление сверху, механизмы снизу, выходы справа.
3. `03_Flowchart_BottomUp_Loop.drawio` — алгоритм подсчёта рабочих дней перебором дат. Начало и конец цикла отмечены специальным символом «Граница цикла» из методички; ветви условий выходят из нижних вершин блоков.
4. `04_Flowchart_TopDown_NoLoop.drawio` — расчёт по полным циклам 2/2 и остаточной части без цикла; остаток раскрыт через функцию `W(x)`, которая проверяет, является ли день рабочим.
5. `05_TopDown_Decomposition.drawio` — функциональная декомпозиция решения сверху вниз.

## Редактируемые шаблоны

`06_Drawio_Templates.drawio` содержит четыре страницы: контекстную диаграмму IDEF0 A-0, декомпозицию IDEF0 A0, шаблон блок-схемы и пример использования обозначения границы цикла.

## Принятые допущения

- Вариант 2 — «Приём и регистрация пациента».
- В периоде учитываются обе граничные даты.
- Опорная дата A — последний рабочий день перед двумя выходными; она считается рабочим днём. Рабочие смещения относительно неё: остатки 0 и 3 по модулю 4.
- В блок-схеме алгоритма с циклом использованы специальные обозначения границы цикла для точки входа в цикл и возврата после шага итерации.
- В документе задания не обнаружено явно форматированных цветовым выделением фрагментов; схемы построены по заданиям и варианту из таблицы.
